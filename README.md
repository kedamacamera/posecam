# ポーズカメラ（PoseCam）

ポーズの「型」を画面に重ねて、型に合わせるだけでポーズが決まる iOS カメラアプリ。
美肌・美白・脚長の加工とフィルターをリアルタイムでかけられる。

## 機能

| 機能 | 内容 |
| --- | --- |
| ポーズの型 | 組み込みの 35 種（立ち／かわいい／かっこいい／アクション／座り／上半身）。左右反転を合わせると 70 通り |
| 写真から型を登録 | 写真に写っている人の骨格から型を作り、「マイポーズ」として保存する（一覧で長押しすると削除） |
| 一致度 | 検出した骨格と型を比べて 0〜100% で表示。80% 以上で型が緑になる |
| 自動シャッター | AUTO を ON にすると、一致度 80% 以上を 0.8 秒保ったときに自動で撮影する |
| 美肌・美白 | 肌色の部分だけをなめらかに・明るくする |
| 脚長 | 腰から下を縦に伸ばす（最大 1.2 倍） |
| フィルター | 12 種 |
| 撮影 | 写真（4:3、約 12MP）／動画（1080p・HEVC・音声付き）、前後カメラ切り替え、フラッシュ／ライト、ピンチでズーム |

加工はプレビュー・写真・動画のすべてに同じようにかかる。保存先は写真アプリ。

## ビルド手順（Mac）

必要なもの: Xcode 15 以降、iOS 17 以降の iPhone（シミュレーターにはカメラがないので実機で確認する）

```bash
brew install xcodegen
cd <このフォルダ>
xcodegen generate
open PoseCam.xcodeproj
```

1. Xcode でターゲット **PoseCam** → **Signing & Capabilities** を開き、Team に自分の Apple ID を設定する
2. Bundle Identifier（`com.example.posecam`）を自分のもの（例: `com.<名前>.posecam`）に変える
3. iPhone をつないで実行する。初回は iPhone の「設定 → 一般 → VPN とデバイス管理」で開発元を信頼する

`.xcodeproj` と `Info.plist` は `project.yml` から生成するファイル。設定を変えるときは `project.yml` を編集して `xcodegen generate` を実行し直す。

## 構成

```
PoseCam/
  App/          エントリポイント
  Camera/       セッション管理・Metal プレビュー・録画・写真アプリへの保存
  Processing/   美肌・脚長・フィルター（Core Image）
  Pose/         関節モデル・組み込みポーズ・骨格検出（Vision）・一致度・ライブラリ
  UI/           SwiftUI の画面
```

### ポーズを増やす

`PoseCam/Pose/BuiltInPoses.swift` の `specs` に 1 行足す。角度は 0° が真下、正の値が画面右、180° が真上。
`l〜` は写っている人の左手足（正面を向いたとき画面の右側）。

```swift
PoseSpec(name: "手を振る", category: "アクション", lUpper: 60, lLower: 170),
```

## 制限事項

- 美肌は肌色の範囲で判定しているので、肌に近い色の服や背景もぼける
- 脚長は腰の位置で画像を上下に分けて伸ばしている。腰の高さにある手や物は少し歪む
- タップでのピント合わせはまだない
