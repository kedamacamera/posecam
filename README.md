# ポーズカメラ（PoseCam）

ポーズの「型」を画面に重ねて、型に合わせるだけでポーズが決まる iOS カメラアプリ。
美肌・美白・脚長の加工とフィルターをリアルタイムでかけられる。

## 機能

| 機能 | 内容 |
| --- | --- |
| ポーズの型 | 組み込みの 35 種（立ち／かわいい／かっこいい／アクション／座り／上半身）を人の形の輪郭線で表示。濃さの調整・左右反転・推奨倍率 |
| 写真から型を登録 | 写真に写っている人の骨格から型を作り「マイポーズ」に保存（一覧で長押しすると削除） |
| 一致度・自動撮影 | 型と自分の骨格を比べて 0〜100% で表示。自動撮影を ON にすると 80% 以上を 0.8 秒保ったときに撮影 |
| 美肌・美白 | 人物として認識した領域の中の肌色の部分だけにかける |
| 脚長 | 腰から下を縦に伸ばす（最大 1.2 倍） |
| フィルター | 12 種 |
| レンズ・ズーム | 搭載レンズに合わせた倍率ボタン（例: 0.5 / 1 / 2 / 5）。長押しで細かく調整、ピンチでもズーム |
| 比率 | 3:4 / 9:16 / フル（画面全体） |
| タイマー・連続撮影 | タイマー 3・6・10 秒、1 秒間隔で 3 枚または 10 枚 |
| 動画 | 1080p・HEVC・音声付き。開始と停止で効果音 |
| スナップ | 最大 10 秒の短い動画から、顔がきれいに写っているコマを自動で選び、気に入ったコマを写真として保存 |
| シャッター音の消音 | iOS が許可している機種だけ（日本向けの機種では消せない） |

加工はプレビュー・写真・動画のすべてに同じようにかかる。保存先は写真アプリ。

## ビルドとインストール

手元の Mac（macOS 12）では現行の Xcode が動かないため、GitHub Actions でビルドしている。

1. `main` に push すると `.github/workflows/build-ios.yml` が署名なしの `.ipa` を作る（10 分ほど）
2. `gh run download <run id> -n PoseCam-ipa -D dist` で `dist/PoseCam.ipa` を取得
3. Windows の Sideloadly で、自分の Apple ID で署名して iPhone に入れる
   - 無料の Apple ID では 7 日で起動できなくなるので、入れ直す

`.xcodeproj` と `Info.plist` は `project.yml` から XcodeGen で生成する（CI の中で行う）。

## 構成

```
PoseCam/
  App/          エントリポイント
  Camera/       セッション管理・レンズ・切り抜き・Metal プレビュー・録画・保存
  Processing/   美肌・脚長・フィルター（Core Image）
  Pose/         関節モデル・組み込みポーズ・骨格と人物領域の検出（Vision）・一致度・ライブラリ
  UI/           SwiftUI の画面（撮影画面・各種パネル・スナップのコマ選択）
  Util/         スレッド間の値の受け渡し・起動時クラッシュの診断
```

### ポーズを増やす

`PoseCam/Pose/BuiltInPoses.swift` の `specs` に 1 行足す。角度は 0° が真下、正の値が画面右、180° が真上。
`l〜` は写っている人の左手足（正面を向いたとき画面の右側）。

```swift
PoseSpec(name: "手を振る", category: "アクション", lUpper: 60, lLower: 170),
```

## 起動時に落ちたとき

カメラの起動中に落ちると、次に開いたときに「どこまで進んで止まったか」の記録が表示される。
「記録をコピー」で内容を取り出せる。iPhone の「設定 → プライバシーとセキュリティ → 解析と改善 → 解析データ」にある `PoseCam-…` のクラッシュの記録も原因の特定に使える。

## 制限事項

- 脚長は腰の位置で画像を上下に分けて伸ばしている。腰の高さにある手や物は少し歪む
- スナップで保存する写真は動画のコマなので 1080×1920 になる（写真モードより画素数が少ない）
- タップでのピント合わせはまだない
