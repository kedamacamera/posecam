# ボーン入れツール（Windows・開発者向け）

組み込みポーズの見本写真に、関節・顔・枠を手で入れ直すツールです。
自動の骨格（iPhone の画像解析）は、顔の傾きや腕の位置を読み違えることがあり、
そのまま一致度の判定やガイドの表示に使われていました。ここで直した内容がアプリの型になります。

## 開き方

`pose-editor.bat` をダブルクリックします。ブラウザで編集画面が開きます。
Python 3 が必要です（追加のインストールはいりません）。終わるときは、黒い画面を閉じます。

## 画面

- 左: 見本写真の一覧（カテゴリ・名前・状態で絞り込み）。状態は「未確認」「✓ OK」「● 手直し」。`↑` `↓` で前後の写真へ。
  上に「確認済み ○ / 全部」の数が出ます。
- 手直しが要らない写真は「✓ OK（手直し不要）→ 次へ」（または `Enter`）で OK にすると、次の未確認の写真へ進みます。
  もう一度押すと取り消し。手直しした写真は自動で確認済みになります。
- 中央: 写真。ホイールで拡大縮小、右ドラッグか Space＋ドラッグで移動。
  - 関節・顔（B）: 関節の丸をドラッグ。顔は点線の丸で位置、緑の丸で大きさと傾き。
    右の「向き」で顔の左右の向き（正面 0°、画像の右を向くと +）。
    目・鼻・口・あごの輪郭は白い縁の点をドラッグ（口は◇で形ごと、あごの輪郭は 9 点・赤い点があご先）。
    「複数選択」をオンにすると、ドラッグで囲んだ点をまとめて動かせます（選んだ点のどれかをドラッグ）。
    点を押すとその点だけを選び、Shift・Ctrl を押しながらだと選択に足します。顔の中心を選ぶと顔ごと動きます。
    右の「関節・顔のパーツ」の図に、関節と顔のパーツがボタンで並んでいます。入っているものは色つき、
    ないもの（未使用）は灰色の点線。押すと足す・消すが切り替わります（足した関節は枠の中央に出るので、ドラッグで合わせる）。
    「鼻を描く」「口を描く」を押すと、写真の上にペン（マウスは左ドラッグ）で鼻・口の線を直接描けます。何本でも描け、
    消しゴム側でなぞると描いた線を消します。終わるときはもう一度押すか `Esc`。描いた線があると、アプリは自動の鼻の形・
    唇の輪郭の代わりにその線をガイドに描きます（目・鼻・口は表示だけで、一致度には使いません）。
    要らない関節は選んで `Delete` でも消せます。
  - 枠（C）: 黄色い枠が撮影画面に重なる範囲（3:4）。中をドラッグで位置、四隅で大きさ。
    「写真よりガイドがアップぎみ」などは、ここで枠を広げると直ります。
- 2 人以上写っている写真: 右の「人」で 1人目・2人目…を切り替え、人ごとに関節と顔を入れます。
  写真の上で別の人（薄い色の骨格）の関節を押しても切り替わります。
  自動で見つからなかった人は「＋人を足す」（1 人目の形を写して右に置く）、要らない人は「○人目を消す」。
- 右: アプリの撮影画面での見え方（枠の中の写真に、輪郭・骨格・顔のガイドを重ねたもの）。

## 液タブ・タッチ

- ペン先でドラッグ。ペンを浮かせて近づけると関節が光ります。
- サイドボタンを押しながら（または何もない所を）ドラッグで写真を移動。消しゴム側で関節に触れると消えます。
- 指 2 本でつまんで拡大縮小。写真の右上のボタンで拡大縮小・前後の写真・戻す・OK。

## 保存すると

- `tools/pose-editor/pose_edits.json` … 手直しした内容（写真の上の座標。手直しの元データ）
- `tools/pose-editor/pose_checked.json` … OK（手直し不要）にした写真の一覧（アプリの型には影響しません）
- `PoseCam/Resources/Poses/builtin_shapes.json` … アプリが読む型。解析結果と手直しから作り直す

アプリに入れるには、これらをコミットしてプッシュします（GitHub Actions でアプリがビルドされます）。

## 解析結果（builtin_analysis.json）

`builtin_analysis.json` は Mac で自動解析した結果です（見本写真ごとの関節・顔・輪郭・自動の枠）。
見本写真を足したり差し替えたりしたときは、GitHub Actions の「Build pose shapes」を実行し、
出力の `builtin_analysis.json` をこのフォルダに置き直してから、このツールで保存し直してください。

画面を開かずに `builtin_shapes.json` だけ作り直すときは `python server.py --export`。
