# ボーン入れツール（Windows・開発者向け）

組み込みポーズの見本写真に、関節・顔・枠を手で入れ直すツールです。
自動の骨格（iPhone の画像解析）は、顔の傾きや腕の位置を読み違えることがあり、
そのまま一致度の判定やガイドの表示に使われていました。ここで直した内容がアプリの型になります。

## 開き方

`pose-editor.bat` をダブルクリックします。ブラウザで編集画面が開きます。
Python 3 が必要です（追加のインストールはいりません）。終わるときは、黒い画面を閉じます。

## 画面

- 左: 見本写真の一覧（カテゴリ・名前で絞り込み、手直しした写真には「● 手直し」）。`↑` `↓` で前後の写真へ。
- 中央: 写真。ホイールで拡大縮小、右ドラッグか Space＋ドラッグで移動。
  - 関節・顔（B）: 関節の丸をドラッグ。顔は点線の丸で位置、緑の丸で大きさと傾き。
    右の「向き」で顔の左右の向き（正面 0°、画像の右を向くと +）。
    見つからなかった関節は右の「＋左ひざ」などで足し、要らない関節は選んで `Delete`。
  - 枠（C）: 黄色い枠が撮影画面に重なる範囲（3:4）。中をドラッグで位置、四隅で大きさ。
    「写真よりガイドがアップぎみ」などは、ここで枠を広げると直ります。
- 右: アプリの撮影画面での見え方（枠の中の写真に、輪郭・骨格・顔のガイドを重ねたもの）。

## 保存すると

- `tools/pose-editor/pose_edits.json` … 手直しした内容（写真の上の座標。手直しの元データ）
- `PoseCam/Resources/Poses/builtin_shapes.json` … アプリが読む型。解析結果と手直しから作り直す

アプリに入れるには、この 2 つをコミットしてプッシュします（GitHub Actions でアプリがビルドされます）。

## 解析結果（builtin_analysis.json）

`builtin_analysis.json` は Mac で自動解析した結果です（見本写真ごとの関節・顔・輪郭・自動の枠）。
見本写真を足したり差し替えたりしたときは、GitHub Actions の「Build pose shapes」を実行し、
出力の `builtin_analysis.json` をこのフォルダに置き直してから、このツールで保存し直してください。

画面を開かずに `builtin_shapes.json` だけ作り直すときは `python server.py --export`。
